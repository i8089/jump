# Jump

A jump rope interval timer. One page, no build step, no dependencies.

**Live:** https://i8089.github.io/jump/

**Install on iPhone:** open the link in Safari, then Share → Add to Home Screen.

**Shipping a change:** push to `main` and GitHub Pages deploys it in a few minutes.
Bump `CACHE` in `sw.js` on every release, or installed copies keep the old files.

Settings are stored on the device (`localStorage`, key `jump.cfg.v1`).
